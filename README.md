# bjornoslott-garden

An interactive GitHub Pages project documenting the garden at Björnö Slott in Kalmar.

## What this project contains

- A static plant inventory (`/data/plants.json`) with:
  - plant or tree name
  - planted timestamp
  - location
  - details
- An interactive map page (`/index.html`) centered at `56.7705576, 16.3833692` where each mapped plant/tree can be clicked to query its information.

## Hosting

This repository is intended to be hosted as a GitHub Page.
