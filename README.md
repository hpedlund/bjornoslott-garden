# bjornoslott-garden

An interactive GitHub Pages project documenting the garden at Björnö Slott in Kalmar.

## What this project contains

- A static plant inventory (`/data/plants.json`) with:
  - plant or tree name
  - planted year
  - area
  - location
  - details
- An interactive map page (`/index.html`) where each mapped plant/tree can be clicked to view details in a popup.
- A year selector to view time progression snapshots (for example 1860 and 2026).
- Progressive Web App support with a web manifest and service worker.

## Hosting

This repository is intended to be hosted as a GitHub Page.
